# 06 约定与坑

## 约定

### 分层与命名

- Controller调Service接口，impl做业务再调Mapper；仍多为字段@Autowired，也有构造注入（`src/main/java/com/winniethepooh/hotelsystembackend/controller/OrderController.java:30-31`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:38-41`、`src/main/java/com/winniethepooh/hotelsystembackend/controller/UploadController.java:22-25`）。
- 方法惯用Controller/Service后缀，载体分DTO/entity/VO；Mapper与XML同名、namespace绑定；RedisConfig仍在service包（`src/main/java/com/winniethepooh/hotelsystembackend/controller/RoomController.java:27-32`、`src/main/java/com/winniethepooh/hotelsystembackend/service/RoomService.java:12-24`、`src/main/resources/mapper/RoomMapper.xml:4`、`src/main/java/com/winniethepooh/hotelsystembackend/service/RedisConfig.java:9-21`）。
- Lombok @Data生成访问器；员工VO用BeanUtils，房间手动转换，订单总览JOIN直接映射VO（`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/StaffServiceImpl.java:79-82`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/RoomServiceImpl.java:47-60`、`src/main/resources/mapper/OrderMapper.xml:199-207`）。
- 部分请求用@Valid字段约束，分页用MVC原生方法参数@Min/@Max，无类级@Validated；并非所有DTO都校验（`src/main/java/com/winniethepooh/hotelsystembackend/controller/OrderController.java:43-58`、`src/main/java/com/winniethepooh/hotelsystembackend/controller/StaffController.java:91-94`、`src/main/java/com/winniethepooh/hotelsystembackend/dto/StaffRegisterDTO.java:6-11`）。
- 日期既有显式yyyy-MM-dd也有未标注LocalDate；测试用ISO日期，Q2契约依据见README（`src/main/java/com/winniethepooh/hotelsystembackend/controller/BusinessController.java:26-34`、`src/main/java/com/winniethepooh/hotelsystembackend/controller/BusinessController.java:75`、`src/main/java/com/winniethepooh/hotelsystembackend/controller/RoomController.java:30`、`src/test/java/com/winniethepooh/hotelsystembackend/PriceCalendarIT.java:103-109`）。

### 并发与事务

- USER与FRONT公开下单入口均@Transactional，内部共用私有流程；房间FOR UPDATE先于重叠检查与入住人/主单/夜价写入。时刻区间[checkin,checkout)，未付进行中也占区间；取消/完成/软删排除（`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:94-124`、`src/main/resources/mapper/RoomMapper.xml:17-21`、`src/main/resources/mapper/OrderMapper.xml:99-104`）。
- 改期@Transactional，换房按id升序锁两房，再锁读订单确认进行中与房间未变；重算金额，物理删全部夜价再写；失败回滚（`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:129-158`）。
- 支付/取消单条条件UPDATE，0行后才读订单区分不存在/归属/状态；已付取消只记pay_status2，无支付渠道（`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:165-188`、`src/main/resources/mapper/OrderMapper.xml:126-138`）。
- 餐饮下单@Transactional，落主单前校验菜品/价格；房态修改、删分类有事务；员工删除rollbackFor RuntimeException（`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:225-247`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/RoomServiceImpl.java:64-73`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/FoodServiceImpl.java:59-63`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/StaffServiceImpl.java:61-66`）。
- 三个cron均@Transactional；只有releaseExpiredRooms通过scheduler_task_lock抢占本分钟退房批次，锁与整批同事务；异常回滚数据库写入，代码没有失败重试机制。入住/超时依赖条件UPDATE，房间仅0→1或1→2，不覆盖清洁/维修（`src/main/java/com/winniethepooh/hotelsystembackend/service/CustomTaskScheduler.java:29-57`、`src/main/resources/mapper/OrderMapper.xml:163-170`、`src/main/resources/mapper/RoomMapper.xml:23-27`）。
- 注册仍user/individual两次写库，无@Transactional；员工停用也无事务；MySQL事务不含Redis撤销，不能推断跨库原子性。价格日历是一条UPSERT，无Service事务（`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/UserServiceImpl.java:28-39`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/StaffServiceImpl.java:50-66`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/BusinessServiceImpl.java:262-264`）。

### 助手约定

- 助手代码集中在 agent 包，构造注入、final 字段；工具参数用 record + Jackson 注解描述，同一组 record 既给 OpenAI SDK 生成 JSON Schema，也给本地解析（`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentTools.java:62-117`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/OpenAiLlmClient.java:93-96`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentTools.java:211-218`）。
- 写操作一律「propose 建卡 → 住客确认」两步，确认阶段只调用原有 OrderService 方法，不在 agent 包里另写订单 SQL（`src/main/java/com/winniethepooh/hotelsystembackend/agent/PendingActionService.java:118-147`）；只读工具也复用 OrderService / FoodService / Mapper（`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentTools.java:220-262`）。
- 用户身份在三处被重新取：Controller 从 BaseContext 传 userId，工具执行前比对 BaseContext 与会话 userId，确认时比对卡片 / 记录归属；被复用的 `insertRoomOrderByUserService`、`payRoomOrderService`、`cancelRoomOrderService` 仍从 BaseContext 取用户，所以确认必须在原请求线程内执行（`src/main/java/com/winniethepooh/hotelsystembackend/controller/AgentController.java:38-45`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentTools.java:128-133`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/PendingActionService.java:185-187`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:103`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:166`、`src/main/java/com/winniethepooh/hotelsystembackend/service/impl/OrderServiceImpl.java:174`）。
- 时间预算用 ThreadLocal 的 AgentDeadline 传递：Lettuce 命令超时、Hikari 取连接、Connection 网络超时、Statement 查询超时都读它；工具事务用 TransactionTemplate 并把超时设为剩余秒数（`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentDeadline.java:8-43`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentIoConfiguration.java:25-109`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentTools.java:148-154`）。
- SSE 手写：`event: 名\ndata: 单行JSON\n\n`，每个事件 flush；事件名固定 status / delta / card / error / done，done 总是最后一个（浏览器断开时除外）（`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentService.java:145-148`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentService.java:127`）。
- 日志不写参数原文：工具日志只记工具名白名单和安全摘要（日期、长度、是否有 id），模型日志只记 token 数、耗时、结果；错误只记异常类名（`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentTools.java:119-125`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentTools.java:191-203`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/OpenAiLlmClient.java:170-173`、`src/main/java/com/winniethepooh/hotelsystembackend/agent/AgentService.java:123`）。
